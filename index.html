NikaCRM Backup

NikaCRM Backup is a personal utility designed to help its operator create, verify, compare and restore database backup archives for the NikaCRM service-management application.

What it does

The utility supports local backup storage and Google Drive backup storage. It is intended to verify backup archives before use and let the operator choose whether to restore a selected copy.

Google Drive access

When enabled by the operator, the utility uses Google's authorization system to access Google Drive for backup-related operations. Access is used to locate, upload, download and verify backup archives. Restoring a database is an explicit operator action.

Privacy

The utility is intended for personal use. Backup files are stored on locations selected by the operator, such as a local computer, removable drive or the operator's Google Drive account. The project does not operate a separate service for collecting or selling Google user data.
