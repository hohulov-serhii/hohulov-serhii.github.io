Privacy Policy

NikaCRM Backup

Last updated: October 10, 2026

Purpose

NikaCRM Backup is a personal utility intended to create, verify, compare and restore database backup archives for the NikaCRM service-management application.

Google Drive data access

If the operator connects Google Drive, the utility uses Google's authorization system and Drive API to access files and folders needed for backup operations. This may include listing file names, reading file metadata, uploading backup archives, and downloading selected archives for verification or restoration.

The configured Drive permission may technically allow broader access than the backup folder. The intended use is limited to the locations and backup operations selected by the operator.

How data is used

Google Drive data is used only to manage and verify backup archives, compare available copies, and support an operator-requested restore. The utility does not sell Google user data or use it for advertising.

Storage and sharing

Backup archives are stored on locations selected by the operator, such as a local computer, removable drive, or the operator's Google Drive account. Archives may contain customer and service records from the NikaCRM database.

OAuth credentials and access tokens are intended to remain in the local configuration of the computer running the utility. They must not be published in this repository or shared publicly. The project does not operate a separate server that collects or sells Google Drive data.

Security and retention

Access is granted by the Google account owner and can be revoked through the account's security settings. Backup copies are retained at the locations selected by the operator. The operator is responsible for protecting the computer, removable drives, Google account and stored backup archives.

Contact

For questions about this personal project or this policy, contact the project owner through the contact information provided with the repository.
